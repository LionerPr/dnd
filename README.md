# Летопись

Веб-приложение для кампаний D&D 5e: интерактивный лист персонажа, комната мастера с боем и врагами, достижения, библиотека рас, классов и заклинаний с импортом с dnd.su.

## Быстрый запуск на своём компьютере

Нужен [Node.js 22](https://nodejs.org) или новее.

```bash
corepack enable          # включает pnpm
pnpm install
pnpm --filter @dnd/web build
pnpm --filter @dnd/server start
```

Откройте http://localhost:3000. Данные хранятся в папке `data/` рядом с проектом.

Чтобы друзья зашли к вам из интернета, нужен туннель, например `npx cloudflared tunnel --url http://localhost:3000`: он выдаст временную ссылку https://….trycloudflare.com.

## Запуск в Docker / на хостинге

```bash
docker build -t letopis .
docker run -p 3000:3000 -v letopis-data:/data letopis
```

На Railway, Render или Fly.io достаточно указать этот репозиторий: Dockerfile подхватится сам. Подключите постоянный диск в `/data` или задайте `DATABASE_URL` своей базы PostgreSQL.

| Переменная | Что делает |
|---|---|
| `PORT` | порт, по умолчанию 3000 |
| `DATA_DIR` | где лежит встроенная база, по умолчанию `data/pglite` |
| `DATABASE_URL` | внешняя PostgreSQL вместо встроенной |
| `SECURE_COOKIES=true` | включить, когда сайт открыт по https |

## Первые шаги

1. Зарегистрируйтесь: первый пользователь становится администратором.
2. «Библиотека» → «Загрузить разделы dnd.su целиком» → «Всё сразу»: расы, классы и заклинания (около 25 минут, можно пользоваться сайтом параллельно).
3. На главной создайте кампанию и отправьте игрокам код приглашения.
4. Игроки регистрируются, создают героя в «Конструкторе» и вступают по коду.
5. Комната кампании: урон и лечение, деньги, состояния, враги из бестиария, инициатива, тайные броски, журнал с отменой, достижения.

## Разработка
