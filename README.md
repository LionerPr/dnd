# Летопись

Веб-приложение для кампаний D&D 5e: интерактивный лист персонажа, комната мастера с боем и врагами, достижения, библиотека рас, классов и заклинаний с импортом с dnd.su.

Работает на бесплатном тарифе Cloudflare: воркер с API, база D1, живые комнаты на Durable Objects, интерфейс — статикой с того же адреса. Сайт всегда онлайн, свой компьютер держать включённым не нужно.

## Выкладка на Cloudflare (один раз)

Нужны аккаунт на [cloudflare.com](https://dash.cloudflare.com/sign-up) (бесплатный) и [Node.js 22](https://nodejs.org) или новее.

```bash
corepack enable                      # включает pnpm
pnpm install
npx wrangler login                   # откроет браузер для входа в Cloudflare
npx wrangler d1 create letopis       # создаст базу и покажет database_id
```

Впишите выданный `database_id` в `wrangler.jsonc` в корне, затем:

```bash
npx wrangler deploy                  # соберёт интерфейс и выложит всё вместе
```

Wrangler напечатает адрес вида `https://dnd.<ваше-имя>.workers.dev` — его и отправляйте игрокам. Таблицы в базе создаются сами при первом запросе.

Обновление после изменений в коде — снова `npx wrangler deploy`. Можно и без компьютера: в панели Cloudflare → Workers & Pages → «Import a repository» подключите репозиторий GitHub с настройками по умолчанию (команда выкладки `npx wrangler deploy`). Тогда каждый push выкладывается сам.

### Хватит ли бесплатного тарифа

Для своей игровой группы — с большим запасом: 100 000 запросов в день, 5 ГБ базы, 5 млн чтений строк в день. Разбор страниц dnd.su идёт в браузере администратора, потому что серверу на бесплатном тарифе дано лишь ~10 мс процессора на запрос.

## Первые шаги

1. Зарегистрируйтесь: первый пользователь становится администратором.
2. «Библиотека» → «Загрузить разделы dnd.su целиком» → «Всё сразу»: расы, классы и заклинания. Это около 15–25 минут, вкладку нужно держать открытой.
3. «Создать или войти в комнату» → «Мастер» → название. Код приглашения появится в комнате.
4. Игроки: «Создать или войти в комнату» → «Приключенец» → код, затем свой герой или новый.
5. Комната кампании: урон и лечение, деньги, состояния, враги из бестиария, инициатива, тайные броски, журнал с отменой, достижения.

## Разработка

```bash
pnpm install
pnpm --filter @dnd/web build
npx wrangler dev                     # всё приложение на http://localhost:8787 с локальной базой
pnpm --filter @dnd/web dev           # (по желанию) интерфейс с горячей перезагрузкой на :5173
pnpm -r test                         # правила, разбор dnd.su и сквозной тест API в локальном Cloudflare
```
